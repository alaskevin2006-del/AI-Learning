## 模块 2/6｜计算机系统的组成与层次结构

 课件 1.1 · P64—76｜本模块目标：理解硬件、软件如何分工，以及计算机为什么需要分层。 1. 计算机系统由什么组成？ 课件将计算机系统分为两部分： 类别 含义 例子 硬件 计算机的物理实体 CPU、存储器、输入输出设备 软件 实现特定功能的程序及相关信息 操作系统、编译程序、应用程序 软件又分为两大类： 系统软件： 管理计算机系统、为其他软件提供运行支持，如操作系统、语言处理程序。 应用软件： 面向具体任务，如浏览器、文本编辑器。 

重点理解：硬件提供基本计算能力，软件组织和利用这些能力来完成具体任务。 2. 为什么计算机需要层次结构？ 假设你写了一句 C++： int c = a + b; 你不需要知道 CPU 内部哪些电路在工作，就能完成加法。 这是因为计算机系统通过不同层次隐藏了底层实现细节。每一层都向上一层提供更容易使用的功能。 结合课件 P71—76，可以概括为： 高级语言层 C++ 等高级语言 汇编语言层 用符号形式表示机器操作 操作系统层 管理资源、提供系统服务 机器语言层 CPU 能够识别的机器指令 微程序层 在采用微程序控制的机器中实现指令控制 这是课件中的教学层次模型，不意味着每台计算机都必须采用完全相同的内部实现，也不意味着程序必定逐层经过图中的每一种表示。 

这里需要两个术语： 编译： 把程序翻译为较低层次的代码，使其能够进一步转换或执行。 汇编： 把汇编语言程序翻译为机器语言程序。 课件中还使用了「虚拟机器」这一概念。这里的意思是：在底层机器提供的功能之上，构造一个更便于编程和使用的抽象层次。 暂时不要把它与 VMware 等虚拟机软件混为一谈。 因此，分层的核心意义是： 通过层次抽象隐藏底层实现细节，使上层能够利用下层提供的功能，而不必直接处理全部硬件细节。 3. 集中诊断（3 题） 一次作答即可，不需要逐题发送。 1. 为什么只有 CPU、内存等硬件，还不足以构成一个方便使用的完整计算机系统？

1，故也称为计数器。PC存的永远是下一条要执行的指令。因为每次读完上一个指令后，就会马上读取PC。对于上个指令而言，现在的PC就是下一条指令的地址。读完PC后，就得到了当前要读的指令的地址。此时，只要一读，PC就会马上更新，保证PC存的永远是下一条指令的地址。然后，CU就会拿着这个指令的地址去存储器里面取具体的指令，把它存在IR里面，然后再进行执行。再讲一下存储器。存储器由存储体构成，存储体由存储单元构成，存储单元由存储元件构成。一个存储元件代表一位（bit），存储单元由多位组成，其位数即为字长。可以把存储单元比作房间，位比作床位，只有0和1两种状态。每个存储单元都有地址，相当于门牌号，整个存储体就像一家大酒店。 

指令执行流程大致如下：CPU首先从PC读取指令地址并更新PC，将地址存入MAR，存储器将对应指令存入MDR，MDR再将指令传回IR，最后执行IR中的指令。即先取指，再执行。若指令涉及取数，同样将数据地址存入MAR，从存储器读取数据至MDR，再存入相应位置。 现在明确了存储器和存储体的关系：存储器由存储体和MAR（地址寄存器）、MDR（数据寄存器）构成。取数据时，MAR存放地址，结果返回至MDR；存数据时，MAR和MDR同时操作，将MDR中的数据存入MAR对应的地址。 最后讲衡量计算机性能的指标，主要涉及几个概念： 

1. 节拍：协调同步电路时序的基本单位。 2. 时钟周期：完成一个节拍所需的时间。 3. 主频：时钟周期的倒数，表示每秒能完成的节拍数。 4. CPI（Cycles Per Instruction）：执行一条指令平均所需的时钟周期数（或节拍数）。单位通常为GHz，需注意G（十亿）及赫兹的换算。 5. MIPS：具体概念记不清了。 差不多就这样。 …
