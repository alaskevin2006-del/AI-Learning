## 二、已获得的独立掌握证据

- 能自主说明五大功能部件的存在理由，正确给出 `CPU=运算器+控制器`、`主机=CPU+主存`。
- 能区分 PC、IR、MAR、MDR、ACC、ALU 的基本职责，明确 MAR 只暂存地址、ALU 运算而 ACC 暂存结果。
- 经过反复纠错后，独立完成 LOAD 取指与取数过程、STORE 写地址与写数据的专项复验。
- 能独立跟踪 `LOAD a → MUL x → ADD b → MUL x → ADD c` 的 ACC 状态。
- 能解释 `(ax+b)x+c` 的中间结果复用和额外访存减少。
- 能在新例题中计算 MAR/MDR 对应的按字编址存储容量，并正确转换 bit 与 Byte。
- 能独立计算 `执行时间=指令数×CPI/主频`，得到正确时间结果。
- 完成一次**自由闭卷整章复述**，可按“计算自动化 → 存储程序 → 五大部件 → 指令与程序 → 取指执行 → 性能指标”建立初步自有叙事链。
