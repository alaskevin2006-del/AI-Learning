# AI-Learning

基于课程材料的 AI 辅助自主学习。目标是以**单位时间的真实、稳定、可迁移能力提升**为标准，而非以完成对话或阅读页数为标准。

## 工作流程

```text
导入课件/教材/课堂转写
  → 课前教学地图（一次性覆盖全章）
  → 模块讲解（先完整讲，再集中提问）
  → 定点纠错与疑问暂存
  → 模块独立复述与归档
  → 会话结束：历史问题复验 + 整体独立复述
  → 学习结算 + 更新当前进度
```

模块可以跨会话；一次会话也可以学习多个模块。中途结束仍须结算真实进度。

## 目录约定

```text
<课程>/<章节>/
├── 00-教学地图.md             # 课前建立：目标、知识点、案例、范围
├── 01-当前进度.md             # 唯一最新状态，供续学
├── 02-认知问题索引.md         # 问题 ID、状态、历史证据位置
├── 模块记录/<模块ID>/
│   ├── <会话ID>-原始对话.md
│   ├── <会话ID>-独立复述.md
│   └── <会话ID>-认知问题.md
└── 会话记录/<会话ID>/
    ├── 整体独立复述.md
    └── 学习结算.md
```

- **模块与会话记录不可变**：一经归档，后续学习另建文件；只更新 `01-当前进度.md`、`02-认知问题索引.md` 等索引。
- **学习者复述保留原文**：AI 校准必须另起区域，不替换学习者表述。
- **命名**：模块 `M01`、`M02`；会话 `SYYYYMMDD-01`；认知问题 `CH01-M02-Q001`。同一问题复验沿用原 ID。
- **本地优先**：GPT 在对话内生成可下载 Markdown / ZIP，用户下载到本地并自行同步 GitHub；GPT 不直接修改仓库。

## 新会话如何继续

将本章的 `00-教学地图.md`、`01-当前进度.md` 和 `02-认知问题索引.md` 提供给 AI；必要时补充最近的独立复述。不必重新上传全部历史对话。AI 先报告当前节点与下一步，再开始教学。

## 文档职责

- `README.md`：面向学习者的使用入口。
- `AGENTS.md`：面向 AI 的执行契约；教学与归档以此为准。
